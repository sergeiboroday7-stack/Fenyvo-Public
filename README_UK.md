# FENYVO

[English](README.md) | [Українська](README_UK.md) | [Русская](README_RU.md)

**Месенджер для Android і Windows**

FENYVO — застосунок для особистих і групових чатів, голосових і відеодзвінків та обміну медіафайлами.

## Завантажити

Версія **1.8.0**, збірка **4234**.

- [Android APK](https://fenyvo.com/download/Fenyvo-1.8.0-arm64.apk)
- [Windows ZIP](https://fenyvo.com/download/Fenyvo-1.8.0-windows-x64.zip)

Офіційний сайт: https://fenyvo.com

## Можливості

- Особисті та групові чати
- Голосові та відеодзвінки
- Групові дзвінки
- Надсилання медіафайлів
- Функції наскрізного шифрування
